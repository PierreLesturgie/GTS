# GTS - Gene Tree Statistics Tool
---
### Author: Pierre Lesturgie (pierrelesturgie@outlook.fr)

### (1) Installation: 

#### 1. Create env conda: 

```conda create --name GTS python=3.12```

```conda activate GTS```

#### 2. Install: 

```pip install . ```

#### Note: iF error occurs related to msprime: 

```pip uninstall msprime```
```pip install msprime```
